🔧 3 Bước đơn giản để nạp:
1
Giữ nút BOOT (GPIO0) → Nhấn nút RST → Thả BOOT để vào chế độ nạp.
2
Nhấn nút Nạp Firmware ở trên → Chọn cổng USB JTAG/Serial của ESP32-S3.
3
Nạp xong: Nhấn nút RST để khởi động. Kết nối Wi-Fi ESP32S3-CAM-SETUP (Pass: 12345678) rồi vào 192.168.4.1.
